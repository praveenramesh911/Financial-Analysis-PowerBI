**# Financial Analysis – Power BI Project Documentation**



\## 1. Project Overview



This project presents an interactive Financial Analysis dashboard developed using Microsoft Power BI.



The dashboard compares actual financial performance with budgeted values and provides insights into income, expenses, and financial variances across different years.



\## 2. Business Objective



The main objective of this project is to provide a clear view of financial performance and help users compare actual results against planned budgets.



\### Key Objectives



\- Compare Income Actual with Income Budget

\- Compare Expense Actual with Expense Budget

\- Analyze yearly financial performance

\- Identify income and expense variances

\- Monitor budget utilization

\- Provide interactive financial analysis



\## 3. Dataset



The dataset is stored in an Excel file.



\### Dataset File



`Financial analysis\_Data Set.xlsx`



The dataset contains financial information required for analyzing actual and budgeted income and expenses.



\## 4. Tools and Technologies



\- Microsoft Power BI

\- Power Query

\- DAX

\- Microsoft Excel



\## 5. Dashboard Features



The dashboard includes:



\### KPI Cards



\- Income Budget

\- Income Actual

\- Expense Actual

\- Expense Budget



\### Visualizations



\- Expense Budget vs Expense Actual by Year

\- Income Actual vs Income Budget by Year

\- Expense Actual vs Expense Budget

\- Income Variance %

\- Expense Variance %



\### Filters



\- Month

\- Project ID

\- Year



\## 6. Dashboard Insights



The dashboard allows users to:



\- Compare actual income with planned income

\- Compare actual expenses with planned expenses

\- Identify yearly changes in financial performance

\- Analyze budget differences

\- Understand financial variance percentages
