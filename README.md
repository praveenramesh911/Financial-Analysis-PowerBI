**# Financial Analysis – Power BI**



\## 📊 Project Overview



An interactive Financial Analysis dashboard developed using Microsoft Power BI to compare actual financial performance against budgeted values.



\## 🎯 Business Objectives



\- Compare actual income with budgeted income

\- Analyze actual expenses against budget

\- Identify income and expense variances

\- Analyze financial performance by year

\- Monitor budget utilization



\## 📈 Dashboard Features



\- Income Budget KPI

\- Income Actual KPI

\- Expense Actual KPI

\- Expense Budget KPI

\- Income Actual vs Budget by Year

\- Expense Actual vs Budget by Year

\- Expense variance analysis

\- Income variance analysis

\- Year and project filters



\## 🛠️ Tools Used



\- Microsoft Power BI

\- Power Query

\- DAX

\- Microsoft Excel



\## 📁 Project Structure



\- `Dashboard` – Power BI dashboard file

\- `Dataset` – Financial dataset

\- `Screenshots` – Dashboard preview

\- `Documentation` – Project documentation



\## 📌 Outcome



The dashboard provides an interactive view of financial performance and helps users compare actual results with budgeted values.
